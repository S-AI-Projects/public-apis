Description
<!-- Briefly explain what this PR does and why the change is needed. -->
Implements a self-contained offline fixture test suite to parse and validate API entries under the Music category in README.md, handling clean rows, malformed rows, and unusual URL characters without requiring network connectivity.

Changes Made
<!-- Briefly list the main changes introduced in this PR. -->
• Added `tools/course_checks/r02-t045.py` for offline Music category table parsing and validation.
• Scoped entry checking to the assigned Music entries: `7digital`, `AI Mastering`, and `Audiomack`.
• Added 3 offline fixtures under `work/R02-T045/fixtures/`:
  - `valid.md`: clean table rows matching the catalogue schema.
  - `malformed.md`: malformed table structures (column count mismatch, missing Markdown link).
  - `unusual-urls.md`: URLs with query strings, percent encoding, and anchors.
• Added `--self-test` mode with assertion verification and non-zero exit on failure or when executed with `-O`/`-OO`.
• Provided offline execution validation and environment details under `work/R02-T045/`.
• Documented checker usage and behaviour in `tools/course_checks/README.md`.
