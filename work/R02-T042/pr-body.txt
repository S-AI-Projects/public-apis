Description
<!-- Briefly explain what this PR does and why the change is needed. -->
Adds a conservative, read-only Python checker to detect exact duplicate URLs and potential URL-normalization matches in the Open Data section of the API catalogue, preserving query parameters and meaningful fragments distinct.

Changes Made
<!-- Briefly list the main changes introduced in this PR. -->
• Added `tools/course_checks/r02-t042.py` for conservative duplicate URL detection.
• Implemented exact URL-string duplicate detection.
• Implemented conservative URL normalization for scheme case, hostname case, default ports, and unreserved percent-encoding.
• Preserved query strings, fragments, paths, trailing slashes, and non-default ports distinct to prevent unwarranted merges.
• Added 34 offline self-test checks verifying all normalizations and failure modes.
• Added rejection of assertions disabled mode (`-O`/`-OO`).
• Documented checker usage and behaviour in `tools/course_checks/README.md`.
• Recorded validation evidence, inputs, and results in `work/R02-T042/`.
• Verified that no entries in Open Data require deletion or modification.
